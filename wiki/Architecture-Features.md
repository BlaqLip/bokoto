# Architecture and Features

HTML service pages cover building/plaster, ceilings, interiors/finishing, maintenance, plumbing, solar/geyser energy installation and tiling. `about-us.html` provides company information. Shared CSS and `script.js` implement presentation and interactions.

This repository contains a photograph-based work portfolio. It is a static client website, not a booking/payment or customer-account backend. Client ownership and the developer’s contribution should remain clearly stated.
